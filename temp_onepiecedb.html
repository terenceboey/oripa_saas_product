Search Syntax Guide

Field-Specific Searches

  • name:Luffy - Search card name only
  • type:Character - Card type (Leader, Character, Event, Stage)
  • color:Red - Color (Red, Blue, Green, Black, Purple, Yellow)
  • attribute:Strike - Attribute (Strike, Slash, Wisdom, Special, Ranged)
  • subtype:Straw Hat Crew - Subtype
  • id:OP13-118 - Exact card ID
  • set:OP13 - Set code or name
  • rarity:Secret Rare - Rarity
  • rules:Double Attack - Search in card rules text

Range Queries

  • power:>=5000 - Power greater than or equal to 5000
  • power:<=3000 - Power less than or equal to 3000
  • power:3000-7000 - Power between 3000 and 7000
  • cost:0-3 - Cost between 0 and 3
  • cost:<=5 - Cost less than or equal to 5

Boolean Operators

  • name:Luffy AND color:Red - Both conditions
  • color:Red OR color:Blue - Either condition
  • type:Character NOT color:Green - Exclude condition

Special Keywords

  • rules:On Play - Search in card rules text
  • type:Character - Card type (Leader, Character, Event, Stage)
  • subtype:Straw Hat Crew - Card subtype
  • set:OP13 - Set code or name

Multiple Values

  • color:Red,Blue - Cards that are Red OR Blue
  • subtype:Straw Hat Crew,Supernovas - Cards with either subtype

Examples

  • name:Luffy color:Red
  • power:>=5000 type:Character
  • type:Character rules:On Play
  • color:Red,Blue subtype:Straw Hat Crew
  • attribute:Strike power:3000-7000 cost:<=5
  • (name:Luffy OR name:Zoro) color:Red power:>=5000
  • power:>=5000 cost:<=5 (color:Red OR color:Blue) type:Character
  • subtype:Straw Hat Crew,Supernovas color:Red,Blue power:3000-7000 rules:Double Attack
